EFECTO GLITCH

Por defecto el texto ya lleva su glitch suave —bandas finas y separación de canales siempre presentes, estático y legible— y cada 3 o 4 segundos salta una ráfaga del desgarro fuerte (180–400 ms). Al pasar el ratón (o al enfocarlo con teclado) el fuerte se queda mientras lo tengas encima, con cortes aleatorios que aporta el JavaScript. Efecto exclusivamente del texto.

5 estados · filtros SVG · JS opcional

1. Título grande

Señal comprometida

2. Párrafo completo

Párrafo completo: por defecto el texto ya lleva su glitch suave —bandas finas y separación de canales siempre presentes— y cada 3 o 4 segundos salta una ráfaga del desgarro fuerte (180–400 ms). Al pasar el ratón (o al enfocarlo con teclado) el fuerte se queda mientras lo tengas encima, con cortes aleatorios a texto normal que aporta el JavaScript.

3. Inline

Inline, como cualquier clase: pasa el ratón por aquí y sigue el resto del texto tranquilo.

4. Sin ratón (para capturas)

Truco: añade ?glitch=1 a la URL de ESTA página y todos los ejemplos arrancan ya en fuerte (útil para capturas).

Cómo aplicarlo a cualquier archivo .css

Paso 1: copia todo el contenido de glitch.css dentro de tu hoja de estilos (o guárdalo como archivo y enlázalo con <link>).

Paso 2: pega el bloque <svg> de filtros (el que está al principio de ESTE archivo) una sola vez en la página que quiera usar el efecto —es el equivalente a quien pega el <style> de los efectos CSS.

Paso 3: envuelve el texto en esta etiqueta:

<link rel="stylesheet" href="glitch.css">
<script src="glitch.js"></script>   <!-- cortes + ráfagas (opcional) -->

<a href="#" class="ef-glitch">Enlace con glitch</a>

✓ El JS es opcional: sin él, glitch suave base + ráfagas no ocurren (el hover fuerte sigue siendo CSS+SVG). Con él llegan las ráfagas cada 3-4 s y los cortes aleatorios.

También tienes las instrucciones —incluido el bloque SVG para copiar— en installation-instalacion-glitch.txt de esta misma carpeta.

Notas de uso

  • Sin fondo propio en el elemento con la clase. El filtro se calcula sobre todo lo que pinta el elemento; si la caja tuviera fondo, lo desgarraría también. Si tu bloque necesita fondo, ponlo en el padre y la clase en un <span> interior:
    efecto dentro, caja fuera
  • Estados: base = suave estático · .rafaga = fuerte 180-400 ms (lo pone el JS cada 3-4 s) · hover/focus = fuerte mientras dure · .forzado = fuerte a mano · .sin-glitch = texto normal (corte del JS).
  • Selección e impresión: el texto es texto real del DOM; al imprimir, @media print deja todo en negro liso sin efectos.
  • Movimiento reducido: con prefers-reduced-motion no hay ráfagas ni cortes y el fuerte se mapea al suave (quieto).
