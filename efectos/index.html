🔥 Efectos de texto CSS

Los 11 efectos en una sola página: haz clic en la lista de la izquierda para saltar al que quieras ver. Todo es CSS puro — sin JavaScript, en bucle infinito.

Cada efecto es una clase portable: <span class="efecto-xxx">…</span> (solo el glitch necesita además data-text). Debajo de cada demo tienes el código exacto y los enlaces a su CSS y su documentación.
