================================================================
EFECTO PULSO - CÓMO APLICARLO A CUALQUIER ARCHIVO .CSS
================================================================

PASO 1 - COPIA EL CSS
---------------------
Copia TODO el archivo "pulso.css" dentro de tu hoja de estilos
(o enlázalo desde tu HTML con):

    <link rel="stylesheet" href="ruta/pulso.css">

Contenido del archivo:
  · La clase .efecto-pulso
  · Sus pseudo-elementos ::before y ::after
    (dos anillos de sonar que salen del texto)
  ·   · pulso-anillo, pulso-eco


PASO 2 - AÑADE EL TEXTO EN TU HTML
-----------------------------------
    <span class="efecto-pulso">Tu texto</span>

Ejemplo real:

    <h1><span class="efecto-pulso">PULSO</span></h1>


QUÉ HACE
--------
Dos animaciones en bucle infinito:
  · pulso-anillo (3 s) → cada anillo brota del centro
    escalando de pequeño a grande y se desvanece; el
    ::after lleva 1,5 s de retardo, así que los dos
    salen uno detrás de otro sin cortarse.
  · pulso-eco (3 s) → las letras reciben un destello de
    brillo en el instante exacto en que se emite el ping.
El color base es un degradado azul de interfaz ISAC.

TÉCNICA: background-clip: text (azul) + ::before/::after como
    anillos de sonar con transform scale y opacity, y
    filter brightness para el eco de cada ping.


AJUSTES FÁCILES
---------------
· Pings más seguidos: 3s → 1.6s.
· Anillos más grandes: 2.4em/1.6em → 4em/2.6em.
· Los dos a la vez: quita animation-delay: 1.5s en ::after.
· Anillo más grueso: border 2px → 4px.

================================================================
PULSE EFFECT - HOW TO APPLY IT TO ANY .CSS FILE
================================================================

STEP 1 - COPY THE CSS
---------------------
Copy the WHOLE file "pulso.css" into your stylesheet
(or link it from your HTML with):

    <link rel="stylesheet" href="ruta/pulso.css">

What the file contains:
  · The .efecto-pulso class
  · Its pseudo-elements ::before and ::after
    (two sonar rings leaving the text)
  ·   · pulso-anillo, pulso-eco


STEP 2 - ADD THE TEXT TO YOUR HTML
-----------------------------------
    <span class="efecto-pulso">Tu texto</span>

Real example:

    <h1><span class="efecto-pulso">PULSO</span></h1>


WHAT IT DOES
--------
Two animations on an infinite loop:
  · pulso-anillo (3 s) → each ring springs from the center
    scaling from small to large and fades; the
    ::after carries 1.5 s of delay, so the two
    emerge one right after the other without overlapping.
  · pulso-eco (3 s) → the letters receive a flash of
    brightness at the exact instant the ping is emitted.
The base color is an ISAC interface blue gradient.

TECHNIQUE: background-clip: text (blue) + ::before/::after as
    sonar rings with transform scale and opacity, and
    filter brightness for the echo of each ping.


EASY TWEAKS
---------------
· More frequent pings: 3s → 1.6s.
· Bigger rings: 2.4em/1.6em → 4em/2.6em.
· Both at once: remove animation-delay: 1.5s in ::after.
· Thicker ring: border 2px → 4px.
