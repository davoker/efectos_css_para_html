================================================================
EFECTO GRAFFITI - CÓMO APLICARLO A CUALQUIER ARCHIVO .CSS
================================================================

PASO 1 - COPIA EL CSS
---------------------
Copia TODO el archivo "graffiti.css" dentro de tu hoja de estilos
(o enlázalo desde tu HTML con):

    <link rel="stylesheet" href="ruta/graffiti.css">

Contenido del archivo:
  · La clase .efecto-graffiti
  · Sus pseudo-elementos ::before y ::after
    (dos gotas que se alargan y caen)
  ·   · graffiti-grano, graffiti-goteo


PASO 2 - AÑADE EL TEXTO EN TU HTML
-----------------------------------
    <span class="efecto-graffiti">Tu texto</span>

Ejemplo real:

    <h1><span class="efecto-graffiti">MURAL</span></h1>


QUÉ HACE
--------
Dos animaciones en bucle infinito:
  · graffiti-grano (1,2 s, steps(1)) → las dos capas de
    puntos del grano vibran de posición, como la
    pulverización de la lata aún fresca.
  · graffiti-goteo (4,5 s, ease-in) → cada goteo ::before
    y ::after se alarga desde su origen (las letras), se
    queda colgado un momento y se recoge; van con 2,2 s
    de desfase para no gotear a la vez.
El color base es un degradado morado con halo de spray.

TÉCNICA: background-clip: text con capa de grano
    (radial-gradient de puntos) cuyo background-position
    vibra con steps, y pseudo-elementos goteando con
    transform-origin: top.


AJUSTES FÁCILES
---------------
· Goteos más rápidos: 4.5s → 2.8s.
· Gotas más largas: height .9em → 1.6em.
· Grano más grueso: 7px/9px → 12px/14px en los radial-gradient.
· Morado a verde: #e040fb → #76ff03 (y #651fff → #00c853).

ENGLISH VERSION

================================================================
GRAFFITI EFFECT - HOW TO APPLY IT TO ANY .CSS FILE
================================================================

STEP 1 - COPY THE CSS
---------------------
Copy the WHOLE file "graffiti.css" into your stylesheet
(or link it from your HTML with):

    <link rel="stylesheet" href="ruta/graffiti.css">

What the file contains:
  · The .efecto-graffiti class
  · Its pseudo-elements ::before and ::after
    (two drops that stretch and fall)
  ·   · graffiti-grano, graffiti-goteo


STEP 2 - ADD THE TEXT TO YOUR HTML
-----------------------------------
    <span class="efecto-graffiti">Tu texto</span>

Real example:

    <h1><span class="efecto-graffiti">MURAL</span></h1>


WHAT IT DOES
--------
Two animations on an infinite loop:
  · graffiti-grano (1.2 s, steps(1)) → the two layers of
    grain dots vibrate in position, like the
    spray from the still-fresh can.
  · graffiti-goteo (4.5 s, ease-in) → each drip ::before
    y ::after se alarga desde su origen (las letras), se
    hangs for a moment and retracts; they run with 2.2 s
    of delay so they don't drip at the same time.
The base color is a purple gradient with a spray halo.

TECHNIQUE: background-clip: text with a grain layer
    (radial-gradient of dots) whose background-position
    vibrates with steps, and pseudo-elements dripping with
    transform-origin: top.


EASY TWEAKS
---------------
· Faster drips: 4.5s → 2.8s.
· Longer drops: height .9em → 1.6em.
· Coarser grain: 7px/9px → 12px/14px in the radial-gradients.
· Purple to green: #e040fb → #76ff03 (and #651fff → #00c853).
