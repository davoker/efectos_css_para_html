================================================================
EFECTO RAVENCLAW - CÓMO APLICARLO A CUALQUIER ARCHIVO .CSS
================================================================

PASO 1 - COPIA EL CSS
---------------------
Copia TODO el archivo "ravenclaw.css" dentro de tu hoja de estilos
(o enlázalo desde tu HTML con):

    <link rel="stylesheet" href="ruta/ravenclaw.css">

Contenido del archivo:
  · La clase .efecto-ravenclaw
  · Sus pseudo-elementos ::before y ::after
    (ala izquierda ::before y ala derecha ::after)
  ·   · hp-ravenclaw-izq, hp-ravenclaw-der, hp-ravenclaw-reflejo


PASO 2 - AÑADE EL TEXTO EN TU HTML
-----------------------------------
    <span class="efecto-ravenclaw">Tu texto</span>

Ejemplo real:

    <h1><span class="efecto-ravenclaw">RAVENCLAW</span></h1>


QUÉ HACE
--------
Tres animaciones en bucle infinito (misma duración, para que
las dos alas se abran a la vez):
  · hp-ravenclaw-izq (5,2 s) → el destello del ala izquierda
    nace en el centro y viaja hacia la izquierda.
  · hp-ravenclaw-der (5,2 s) → el ala derecha hace el mismo
    recorrido en espejo, hacia la derecha.
  · hp-ravenclaw-reflejo (5,2 s) → el brillo del texto sube
    y baja con el batir de las plumas.
La simetría está en los dos keyframes: si cambias uno, cambia
también el otro para que el vuelo siga parejo.

TÉCNICA: degradado azul/bronce con background-clip: text, dos
    pseudo-elementos espejo (::before izquierdo y ::after
    derecho) con gradientes inclinados sincronizados y
    pulso de resplandor en el texto.


AJUSTES FÁCILES
---------------
· Azul más claro: sube el #1e4bb8 del degradado a #2f6fe0.
· Alas más largas: amplía el inset -.5em de los pseudo.
· Vuelo más rápido: 5.2s → 3.4s en los tres keyframes.
· Sin alas: borra los dos pseudo-elementos y sus keyframes.

================================================================
RAVENCLAW EFFECT - HOW TO APPLY IT TO ANY .CSS FILE
================================================================

STEP 1 - COPY THE CSS
---------------------
Copy the WHOLE file "ravenclaw.css" into your stylesheet
(or link it from your HTML with):

    <link rel="stylesheet" href="ruta/ravenclaw.css">

What the file contains:
  · The .efecto-ravenclaw class
  · Its pseudo-elements ::before and ::after
    (left wing ::before and right wing ::after)
  ·   · hp-ravenclaw-izq, hp-ravenclaw-der, hp-ravenclaw-reflejo


STEP 2 - ADD THE TEXT TO YOUR HTML
-----------------------------------
    <span class="efecto-ravenclaw">Tu texto</span>

Real example:

    <h1><span class="efecto-ravenclaw">RAVENCLAW</span></h1>


WHAT IT DOES
--------
Three animations on an infinite loop (same duration, so that
both wings open at the same time):
  · hp-ravenclaw-izq (5.2 s) → the left wing's glint
    starts in the center and travels left.
  · hp-ravenclaw-der (5.2 s) → the right wing makes the same
    mirrored journey, to the right.
  · hp-ravenclaw-reflejo (5.2 s) → the text's shine rises
    and falls with the beating of the wings.
The symmetry is in both keyframes: if you change one, change
the other one too, so the flight stays even.

TECHNIQUE: blue/bronze gradient with background-clip: text, two
    mirror pseudo-elements (::before left and ::after
    right) with synchronized angled gradients and
    a glow pulse in the text.


EASY TWEAKS
---------------
· Lighter blue: raise the gradient's #1e4bb8 to #2f6fe0.
· Longer wings: widen the pseudos' inset -.5em.
· Faster flight: 5.2s → 3.4s in all three keyframes.
· No wings: delete both pseudo-elements and their keyframes.
