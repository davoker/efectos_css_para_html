================================================================
EFECTO HIPERESPACIO - CÓMO APLICARLO A CUALQUIER ARCHIVO .CSS
================================================================

PASO 1 - COPIA EL CSS
---------------------
Copia TODO el archivo "hiperespacio.css" dentro de tu hoja de estilos
(o enlázalo desde tu HTML con):

    <link rel="stylesheet" href="ruta/hiperespacio.css">

Contenido del archivo:
  · La clase .efecto-hiperespacio
  ·   · hiper-estelas, hiper-salto


PASO 2 - AÑADE EL TEXTO EN TU HTML
-----------------------------------
    <span class="efecto-hiperespacio">Tu texto</span>

Ejemplo real:

    <h1><span class="efecto-hiperespacio">HIPER</span></h1>


QUÉ HACE
--------
Dos animaciones en bucle infinito:
  · hiper-estelas (1,1 s) → las estelas horizontales
    vuelan dentro de las letras (la capa mide exactamente
    un período, así que el bucle es invisible).
  · hiper-salto (3,6 s, steps(1)) → cada cierto tiempo
    el texto se estira 1,8 veces y destella en blanco;
    un instante después vuelve a su tamaño, seco.
El color base es un degradado blanco-violeta interestelar.

TÉCNICA: background-clip: text con estelas en
    repeating-gradient (background-position continuo) y
    scaleX+brightness con steps(1) para el salto.


AJUSTES FÁCILES
---------------
· Saltos más seguidos: 3.6s → 2s.
· Estela más rápida: 1.1s → .6s en hiper-estelas.
· Estiramiento mayor: scaleX(1.8) → scaleX(2.4).
· Estelas más gruesas: sube los 46px/52px del repeating.

ENGLISH VERSION

================================================================
HYPERSPACE EFFECT - HOW TO APPLY IT TO ANY .CSS FILE
================================================================

STEP 1 - COPY THE CSS
---------------------
Copy the WHOLE file "hiperespacio.css" into your stylesheet
(or link it from your HTML with):

    <link rel="stylesheet" href="ruta/hiperespacio.css">

What the file contains:
  · The .efecto-hiperespacio class
  ·   · hiper-estelas, hiper-salto


STEP 2 - ADD THE TEXT TO YOUR HTML
-----------------------------------
    <span class="efecto-hiperespacio">Tu texto</span>

Real example:

    <h1><span class="efecto-hiperespacio">HIPER</span></h1>


WHAT IT DOES
--------
Two animations on an infinite loop:
  · hiper-estelas (1.1 s) → the horizontal streaks
    fly inside the letters (the layer measures exactly
    one period, so the loop is invisible).
  · hiper-salto (3.6 s, steps(1)) → from time to time
    the text stretches 1.8 times and flashes white;
    an instant later it snaps back to its size.
The base color is an interstellar white-violet gradient.

TECHNIQUE: background-clip: text with streaks in a
    repeating-gradient (continuous background-position) and
    scaleX+brightness with steps(1) for the jump.


EASY TWEAKS
---------------
· More frequent jumps: 3.6s → 2s.
· Faster streak: 1.1s → .6s in hiper-estelas.
· Greater stretch: scaleX(1.8) → scaleX(2.4).
· Thicker streaks: raise the 46px/52px of the repeating.
