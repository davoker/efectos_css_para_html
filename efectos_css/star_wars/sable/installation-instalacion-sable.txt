================================================================
EFECTO SABLE - CÓMO APLICARLO A CUALQUIER ARCHIVO .CSS
================================================================

PASO 1 - COPIA EL CSS
---------------------
Copia TODO el archivo "sable.css" dentro de tu hoja de estilos
(o enlázalo desde tu HTML con):

    <link rel="stylesheet" href="ruta/sable.css">

Contenido del archivo:
  · La clase .efecto-sable
  · Sus pseudo-elementos ::before y ::after
    (arcos eléctricos en las esquinas)
  ·   · sable-encendido, sable-zumbido, sable-arco


PASO 2 - AÑADE EL TEXTO EN TU HTML
-----------------------------------
    <span class="efecto-sable">Tu texto</span>

Ejemplo real:

    <h1><span class="efecto-sable">SABLE</span></h1>


QUÉ HACE
--------
Tres animaciones en bucle infinito:
  · sable-encendido (5 s) → la hoja SE ENCIENDE cada
    ciclo: el recorte inset(100% 0 0 0) deja ver el
    texto desde abajo arriba con destello, se sostiene
    encendida y luego se apaga del mismo modo.
  · sable-zumbido (1,2 s) → el halo verde de la hoja
    respira con el zumbido característico.
  · sable-arco (1,5 s, steps(1)) → los dos arcos
    eléctricos ::before/::after chisporrotean con las
    fases desfasadas.
El color base es el degradado verde de la hoja.

TÉCNICA: background-clip: text (degradado verde hoja) con
    clip-path animado para el encendido de abajo
    arriba + text-shadow del zumbido + arcos con
    steps().


AJUSTES FÁCILES
---------------
· Encendido más rápido: 5s → 3s.
· Azul (Luke/Rey): #00e676 → #40c4ff en todo el efecto.
· Rojo (Sith): #00e676 → #ff1744 y #00c853 → #b71c1c.
· Halo más marcado: sube el blur de sable-zumbido a 30px.

ENGLISH VERSION
================================================================

================================================================
LIGHTSABER EFFECT - HOW TO APPLY IT TO ANY .CSS FILE
================================================================

STEP 1 - COPY THE CSS
---------------------
Copy the WHOLE file "sable.css" into your stylesheet
(or link it from your HTML with):

    <link rel="stylesheet" href="ruta/sable.css">

What the file contains:
  · The .efecto-sable class
  · Its pseudo-elements ::before and ::after
    (electric arcs in the corners)
  ·   · sable-encendido, sable-zumbido, sable-arco


STEP 2 - ADD THE TEXT TO YOUR HTML
-----------------------------------
    <span class="efecto-sable">Tu texto</span>

Real example:

    <h1><span class="efecto-sable">SABLE</span></h1>


WHAT IT DOES
--------
Three animations on an infinite loop:
  · sable-encendido (5 s) → the blade LIGHTS UP each
    ciclo: el recorte inset(100% 0 0 0) deja ver el
    text from bottom to top with a flash, stays
    lit and then turns off the same way.
  · sable-zumbido (1.2 s) → the blade's green halo
    breathes with the characteristic hum.
  · sable-arco (1.5 s, steps(1)) → the two arcs
    eléctricos ::before/::after chisporrotean con las
    offset phases.
The base color is the blade's green gradient.

TECHNIQUE: background-clip: text (blade green gradient) with
    animated clip-path for the ignition from bottom
    to top + hum text-shadow + arcs with
    steps().


EASY TWEAKS
---------------
· Faster ignition: 5s → 3s.
· Blue (Luke/Rey): #00e676 → #40c4ff across the whole effect.
· Red (Sith): #00e676 → #ff1744 and #00c853 → #b71c1c.
· Stronger halo: raise the blur of sable-zumbido to 30px.
