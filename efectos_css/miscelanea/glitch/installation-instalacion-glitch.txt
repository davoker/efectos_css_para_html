================================================================
EFECTO GLITCH - CÓMO APLICARLO A CUALQUIER ARCHIVO .CSS
================================================================

PASO 1 - COPIA EL CSS
---------------------
Copia TODO el archivo "glitch.css" dentro de tu hoja de estilos
(o enlázalo desde tu HTML con):

    <link rel="stylesheet" href="ruta/glitch.css">

El archivo es 100% portable: no depende de ningún otro estilo,
de librerías ni de JavaScript. Contiene:
  · La clase .efecto-glitch
  · Sus pseudo-elementos ::before y ::after
  · 3 @keyframes: glitch-sacudida, glitch-capa-a, glitch-capa-b


PASO 2 - AÑADE EL TEXTO EN TU HTML
-----------------------------------
    <span class="efecto-glitch" data-text="Tu texto">Tu texto</span>

Ejemplo real:

    <h1><span class="efecto-glitch" data-text="Hola">Hola</span></h1>


ATENCIÓN (lo más importante)
----------------------------
El atributo data-text es OBLIGATORIO y debe repetir EXACTAMENTE
el texto visible. Los pseudo-elementos ::before y ::after usan
    content: attr(data-text)
para crear las dos capas de interferencia (roja y cian). Si no
lo pones, no se verá nada.


QUÉ HACE
--------
Bucle infinito de 4,5 segundos:
  · 0-54%   → ráfagas de interferencia (bandas RGB cortadas)
  · 55-62%  → ráfaga fuerte, muy exagerada
  · 74-95%  → VIBRACIÓN constante del texto
  · 95-100% → pausa breve y vuelve a empezar


AJUSTES FÁCILES
---------------
· Más rápido: cambia 4.5s por 2.5s en las 3 líneas "animation".
· Más fuerte: aumenta los valores de translate(-30px → -50px).
· Otros colores: cambia #ff2a6d (rojo) y #05d9e8 (cian)
  en las reglas ::before y ::after.

================================================================
GLITCH EFFECT - HOW TO APPLY IT TO ANY .CSS FILE
================================================================

STEP 1 - COPY THE CSS
---------------------
Copy the WHOLE file "glitch.css" into your stylesheet
(or link it from your HTML with):

    <link rel="stylesheet" href="ruta/glitch.css">

The file is 100% portable: it doesn't depend on any other style,
on libraries or on JavaScript. It contains:
  · The .efecto-glitch class
  · Its pseudo-elements ::before and ::after
  · 3 @keyframes: glitch-sacudida, glitch-capa-a, glitch-capa-b


STEP 2 - ADD THE TEXT TO YOUR HTML
-----------------------------------
    <span class="efecto-glitch" data-text="Tu texto">Tu texto</span>

Real example:

    <h1><span class="efecto-glitch" data-text="Hola">Hola</span></h1>


ATTENTION (the most important part)
----------------------------
The data-text attribute is MANDATORY and must repeat EXACTLY
the visible text. The ::before and ::after pseudo-elements use
    content: attr(data-text)
to create the two interference layers (red and cyan). If you
don't add it, nothing will show.


WHAT IT DOES
--------
Infinite loop of 4.5 seconds:
  · 0-54%   → interference bursts (chopped RGB bands)
  · 55-62%  → strong burst, very exaggerated
  · 74-95%  → constant VIBRATION of the text
  · 95-100% → brief pause and back to the start


EASY TWEAKS
---------------
· Faster: change 4.5s to 2.5s in the 3 "animation" lines.
· Stronger: increase the translate(-30px → -50px) values.
· Other colors: change #ff2a6d (red) and #05d9e8 (cyan)
  in the ::before and ::after rules.
