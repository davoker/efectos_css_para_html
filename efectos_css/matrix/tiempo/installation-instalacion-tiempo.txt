================================================================
EFECTO TIEMPO BALA - CÓMO APLICARLO A CUALQUIER ARCHIVO .CSS
================================================================

PASO 1 - COPIA EL CSS
---------------------
Copia TODO el archivo "tiempo.css" dentro de tu hoja de estilos
(o enlázalo desde tu HTML con):

    <link rel="stylesheet" href="ruta/tiempo.css">

Contenido del archivo:
  · La clase .efecto-tiempo
  · Sus pseudo-elementos ::before y ::after
    (bala plateada que cruza el texto a cámara lenta)
  ·   · mx-tiempo-lento, mx-tiempo-bala


PASO 2 - AÑADE EL TEXTO EN TU HTML
-----------------------------------
    <span class="efecto-tiempo">Tu texto</span>

Ejemplo real:

    <h1><span class="efecto-tiempo">LENTO</span></h1>


QUÉ HACE
--------
Dos animaciones en bucle infinito:
  · mx-tiempo-lento (6 s) → el texto respira: escala,
    gira apenas un grado y se desenfoca a mitad de
    ciclo, como una cámara que pierde el foco.
  · mx-tiempo-bala (6 s) → una bala con rastro entra
    por la izquierda, recorre el texto muy despacio y
    sale por la derecha estirándose.
La estela azul del text-shadow va en el mismo compás
que el giro: es el rastro del movimiento.

TÉCNICA: transform + filter: blur y text-shadow de estela en
    la clase + pseudo-elemento-bala cuyo left y scaleX
    avanzan lentamente en los keyframes.


AJUSTES FÁCILES
---------------
· Más lento: 6s → 9s en las dos animaciones.
· Estela más larga: sube los 5px/11px del text-shadow.
· Desenfoque mayor: blur(1.6px) → blur(3px).
· Bala más grande: width .7em → 1.2em.

ENGLISH VERSION

================================================================
BULLET TIME EFFECT - HOW TO APPLY IT TO ANY .CSS FILE
================================================================

STEP 1 - COPY THE CSS
---------------------
Copy the WHOLE file "tiempo.css" into your stylesheet
(or link it from your HTML with):

    <link rel="stylesheet" href="ruta/tiempo.css">

What the file contains:
  · The .efecto-tiempo class
  · Its pseudo-elements ::before and ::after
    (silver bullet crossing the text in slow motion)
  ·   · mx-tiempo-lento, mx-tiempo-bala


STEP 2 - ADD THE TEXT TO YOUR HTML
-----------------------------------
    <span class="efecto-tiempo">Tu texto</span>

Real example:

    <h1><span class="efecto-tiempo">LENTO</span></h1>


WHAT IT DOES
--------
Two animations on an infinite loop:
  · mx-tiempo-lento (6 s) → the text breathes: it scales,
    barely turns a single degree and blurs halfway
    through the cycle, like a camera losing focus.
  · mx-tiempo-bala (6 s) → a bullet with a trail enters
    from the left, crosses the text very slowly and
    exits on the right, stretching as it goes.
The blue streak of the text-shadow keeps the same beat
as the rotation: it's the trail of the motion.

TECHNIQUE: transform + filter: blur and a streak text-shadow in
    the class + bullet pseudo-element whose left and scaleX
    advance slowly through the keyframes.


EASY TWEAKS
---------------
· Slower: 6s → 9s in both animations.
· Longer trail: raise the 5px/11px of the text-shadow.
· More blur: blur(1.6px) → blur(3px).
· Bigger bullet: width .7em → 1.2em.
