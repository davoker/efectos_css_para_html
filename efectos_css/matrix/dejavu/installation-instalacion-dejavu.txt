================================================================
EFECTO DEJAVU - CÓMO APLICARLO A CUALQUIER ARCHIVO .CSS
================================================================

PASO 1 - COPIA EL CSS
---------------------
Copia TODO el archivo "dejavu.css" dentro de tu hoja de estilos
(o enlázalo desde tu HTML con):

    <link rel="stylesheet" href="ruta/dejavu.css">

Contenido del archivo:
  · La clase .efecto-dejavu
  · Sus pseudo-elementos ::before y ::after
    (ojos de gato negro que destellan en la esquina)
  ·   · mx-dejavu-eco, mx-dejavu-ojos


PASO 2 - AÑADE EL TEXTO EN TU HTML
-----------------------------------
    <span class="efecto-dejavu">Tu texto</span>

Ejemplo real:

    <h1><span class="efecto-dejavu">OTRA VEZ</span></h1>


QUÉ HACE
--------
Dos animaciones en bucle infinito, ambas por pasos:
  · mx-dejavu-eco (3,4 s) → durante la mayor parte del
    ciclo el texto está quieto; de golpe aparece un eco
    desplazado a la izquierda, salta a la derecha y
    desaparece, como un recuerdo que se repite.
  · mx-dejavu-ojos (3,4 s) → los dos ojos blancos del
    gato se encienden exactamente mientras dura el eco.
steps(1) hace que los cambios sean secos, sin transición.

TÉCNICA: text-shadow y transform por pasos (steps(1)) para el
    eco desfasado + pseudo-elemento con dos degradados
    radiales (los ojos) que parpadea.


AJUSTES FÁCILES
---------------
· Eco más ancho: sube los 4px/5px del text-shadow.
· Más frecuente: 3.4s → 2.2s en las dos animaciones.
· Sin ojos: borra el ::after.
· Eco rojo: #00ff6e → #ff5252 en mx-dejavu-eco.

ENGLISH VERSION

================================================================
DEJAVU EFFECT - HOW TO APPLY IT TO ANY .CSS FILE
================================================================

STEP 1 - COPY THE CSS
---------------------
Copy the WHOLE file "dejavu.css" into your stylesheet
(or link it from your HTML with):

    <link rel="stylesheet" href="ruta/dejavu.css">

What the file contains:
  · The .efecto-dejavu class
  · Its pseudo-elements ::before and ::after
    (black cat eyes flashing in the corner)
  ·   · mx-dejavu-eco, mx-dejavu-ojos


STEP 2 - ADD THE TEXT TO YOUR HTML
-----------------------------------
    <span class="efecto-dejavu">Tu texto</span>

Real example:

    <h1><span class="efecto-dejavu">OTRA VEZ</span></h1>


WHAT IT DOES
--------
Two animations on an infinite loop, both stepped:
  · mx-dejavu-eco (3.4 s) → for most of the
    cycle the text sits still; suddenly an echo shows up
    shifted to the left, jumps to the right and
    disappears, like a memory repeating itself.
  · mx-dejavu-ojos (3.4 s) → the cat's two white eyes
    light up exactly while the echo lasts.
steps(1) makes the changes abrupt, with no transition.

TECHNIQUE: text-shadow and transform in steps (steps(1)) for the
    offset echo + pseudo-element with two
    radial gradients (the eyes) that blinks.


EASY TWEAKS
---------------
· Wider echo: raise the 4px/5px of the text-shadow.
· More frequent: 3.4s → 2.2s in both animations.
· No eyes: delete the ::after.
· Red echo: #00ff6e → #ff5252 in mx-dejavu-eco.
